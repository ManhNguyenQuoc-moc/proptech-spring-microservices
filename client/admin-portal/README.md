# Admin Portal

Standalone Next.js admin/back-office frontend.

## Structure

```text
client/admin-portal/
├── package.json
├── next.config.ts
├── tsconfig.json
├── src/
│   ├── app/
│   ├── components/
│   ├── features/
│   ├── services/
│   ├── store/
│   ├── hooks/
│   ├── lib/
│   └── styles/
└── public/
```

## Dev Server

```powershell
npm install
npm run dev
```

Default port: `3001`.
