# Conventional Commit Guide

## Format

<type>(scope): description

## Types

- feat: New feature
- fix: Bug fix
- refactor: Refactoring
- docs: Documentation
- style: Formatting/UI
- test: Tests
- build: Build changes
- ci: CI/CD changes
- chore: Maintenance

## Examples

feat(auth): add login api
fix(blog): resolve upload issue
refactor(auth): extract middleware
docs(api): update swagger guide
